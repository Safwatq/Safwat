# Open Antenna Tracker

Professional ESP32 Antenna Tracker

## Features

- 📡 ESP32 Web Control
- 🗺 OpenStreetMap
- 🎮 Joystick
- 📱 Mobile Friendly
- 🌙 Dark Theme
- ⚡ WebSocket
- 🛰 Pan & Tilt Control
- 🏠 Home Position
- 🛑 Emergency Stop

## Hardware

- ESP32
- 2x Servo / Stepper
- WiFi
